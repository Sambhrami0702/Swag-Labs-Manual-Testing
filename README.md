# Swag Labs E-Commerce – Manual QA Testing

## Project Overview

Performed manual functional and UI testing of the Swag Labs e-commerce application to evaluate its core user workflows and identify functional issues.

## Testing Covered

- Login and authentication
- Product selection
- Shopping cart
- Checkout workflow
- Input validation
- Functional and UI testing
- Positive and negative test scenarios
- Bug identification and reporting

## Defects Identified

Identified and documented 4 functional defects with:

- Severity
- Steps to reproduce
- Expected result
- Actual result
- Actual impact

## Test Results

- Total test scenarios: 5
- Passed: 2
- Failed: 3
- Pass rate: 40%
